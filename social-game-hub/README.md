# Social Game Hub

A static GitHub Pages social-game hub for quick group play on a phone, tablet, or laptop.

## Install

Upload this folder to your GitHub Pages repository:

```text
your-github.io/
├── index.html
└── social-game-hub/
    ├── index.html
    ├── styles.css
    ├── app.js
    └── README.md
```

Then open:

```text
https://your-username.github.io/social-game-hub/
```

## Features

- Multiple social games
- Large built-in prompt library
- Player setup and turn tracking
- No-repeat prompt draw
- Intensity filter
- Round timer
- Scoreboard
- Favorites
- Custom prompts
- Exportable session history
- Light/dark mode
- Local browser storage
- Mobile-friendly layout

Everything runs locally in the browser. No backend or account is required.
